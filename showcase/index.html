03 / ARCHITECTURE SPECIFICATION

      
Daemon Socket Connection

      

        DockOps connects directly to your local Docker socket via Node.js using the Dockerode SDK. It executes lifecycle requests inside the host system, completely eliminating intermediate layers or third-party daemon interfaces.
      

      

        
    
          
  •  Zero proxy containers required on host.
    • 
          
  •  Direct Unix Socket (/var/run/docker.sock) connection.
    • 
          
  •  Real-time host telemetry utilizing the core engine API.
    • 
        

      

    

    
    

      

         Connection Handler
        dockerode.init()
      

      

        

          Dockerode (Node.js SDK)
          Queries containers list, inspects details metadata, attaches events stream.
        

        

          Unix socket socketPath
          //./pipe/docker_engine or /var/run/docker.sock
        

      

    

  
  
  

    

      

        
03 / QUICKSTART

        
On the dock in 
sixty seconds.

        

          One curl, one up. DockOps ships as a single self-hosted binary that mounts the Docker socket read-write and serves the console on port 8420. Nothing else to install, nothing phoning home.
        

        
        
    
          
  • ◆ Linux • AMD64 / ARM64
    • 
          
  • ◆ Docker Engine > 24.0
    • 
          
  • ◆ No Root Daemon Changes
    • 
        

      


      
      

        

           DOCK@HOST — SH
          
        

        

          
$ curl -fsSL https://get.dockops.dev | sh

          
  pulling dockops:latest ... done (11.2 MB)

          
$ dockops up -d

          
  console live → http://localhost:8420
