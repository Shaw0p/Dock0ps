Full-Spectrum Operations Console

Everything you need to orchestrate container nodes in a beautiful interface without config redundancy.

Docker Compose Lifecycles

Create, edit, validate, and deploy docker-compose YAML files via Monaco editor syntax validation. Pull images, rebuild containers, and watch combined application log streams.

Application Template Catalog

One-click configurations to deploy Redis, PostgreSQL, Nginx, WordPress, and Vault. An dynamic wizard generates compose files automatically with customized ports and envs.

AES-256-GCM Private Registries

Securely configure private credentials (GHCR, GitLab, Hub). Passwords are encrypted at rest using node.js crypto and automatically injected into image pulls based on address matching.

Networks Topologies

Inspect subnet architectures and gateways with an interactive visual topology map showing which containers connect to which bridge nodes, along with IP readouts.

Historical Telemetry

Background collector service records memory, cpu load, blkio, and networking rates every 30s. Renders historical area charts for the last 1 hour of runtime.

Outbound Webhook Alerts

Set rules (e.g. CPU > 85%, Container status stopped) to trigger webhook alerts. Posts formatted JSON payloads directly to Discord or Slack channels when thresholds are crossed.

Direct Daemon Communications

DockOps connects directly to the host's `/var/run/docker.sock` pipe using the Dockerode SDK. It queries container states, volume properties, and network interfaces in real time.

  • No heavy proxy agents required.
  • Zero overhead - Docker daemon is the single source of truth.
  • Subprocess operations are handled via secure, validated arguments.

Initialize DockOps Locally

Run DockOps on your home server or local dev machine in minutes.

Bash command line 
# Clone the repository
git clone https://github.com/shaw0p/Dock0ps.git
cd Dock0ps

# Spin up Postgres development database container
docker compose -f docker-compose.dev.yml up -d

# Install backend packages and run migrations
cd backend
npm install
npx prisma generate
npx prisma migrate dev --name init

# Run backend dev server (starts on port 4000)
npm run dev
